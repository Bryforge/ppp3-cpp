# Chapter 1

Programs and notes for Chapter 1 of *Programming: Principles and Practice Using C++*, Third Edition.

## Build examples

From the repository root:

```bash
gcc ch1/hello.cpp
./hello
```

For a new Chapter 1 exercise, place the source file in this folder:

```text
ch1/name.cpp
```

Then build it from the repository root:

```bash
gcc ch1/name.cpp
./name
```

The PPP support files stay at the repository root and are shared by all chapter folders.
